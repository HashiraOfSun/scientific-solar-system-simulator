# Протокол проверки

## Подтверждено

Среда: macOS 26.5 (25F71), arm64; Apple Clang 17.0.0; CMake 4.4.4. GLFW подключён из установленного Homebrew-пакета, линковка с системным OpenGL.framework и GLM успешна.

- Release-сборка всего приложения с C++17, `-Wall -Wextra -Wpedantic` прошла без предупреждений.
- CTest: один набор `science`, **286 проверок, PASS**.
- Уравнение Кеплера: остаток для e от 0 до 0.999999, положительных/отрицательных аномалий, периодического приведения. Проверка недопустимых параметров.
- Перигелий и афелий, поворот узла, наклон плоскости, правосторонность координат сцены.
- Все 8 планет на границах диапазона, J2000 и 2026-10-21: конечные позиции, допустимый радиус, принадлежность плоскости орбиты.
- Равные площади за равное время, закон P²/a³, отношение скоростей у апсид при фиксированных элементах.
- Наклоны осей, ретроградная ориентация Венеры и Урана.
- Юлианская дата, високосный 2000 год, невисокосный 1900 год, пауза, обратный ход, границы, независимость от частоты кадров с допуском 10⁻⁷ суток.
- Независимость физических координат от визуального масштаба и единый физический масштаб сфер.
- CSV-экспорт всех 9 тел, в том числе при запуске из другой рабочей папки.
- Отдельные проверки CLI: невозможные даты, неверный формат даты, дата за пределом, недопустимый объект и NaN отклоняются; 2000-02-29 принимается.
- Парсер ответа Horizons проверен на синтетическом тексте; это не проверка живого API.

Один CTest-набор содержит 286 отдельных утверждений; это не 286 разных внешних тестовых наборов. Проверки законов Кеплера подтверждают внутреннюю согласованность реализации, но не заменяют сравнение с независимой эфемеридой.

## Не подтверждено в этой среде

Оконный запуск не достиг рендеринга: macOS вернула ошибки `com.apple.hiservices-xpcservice` / `Connection invalid`. Процесс был остановлен. Дополнительная попытка CGL внеэкранного контекста завершилась `Offscreen pixel format unavailable`. Поэтому **нет подтверждённого графического кадра, успешной GPU-компиляции GLSL, измерения FPS или ручной проверки взаимодействия**.

Дополнительный запуск отладочных проверок с AddressSanitizer/UBSan не завершился в среде и был остановлен; его нельзя считать успешной проверкой. Результат 286 PASS относится к обычной Release-сборке.

Запрос к Horizons из локального процесса не получил DNS/сетевой доступ. Таблица ошибок относительно Horizons не создана. Подготовленный инструмент сетевого сравнения не имеет подтверждённого живого прогона.

## Повторить сборку

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel
ctest --test-dir build --output-on-failure
```

Только научное ядро, без GLFW и OpenGL (GLM нужен):

```sh
cmake -S . -B build-core -DBUILD_VIEWER=OFF
cmake --build build-core --parallel
ctest --test-dir build-core --output-on-failure
```

Научное ядро не зависит от macOS API; viewer намеренно поддерживает macOS. Сборка ядра на Linux/Windows здесь не выполнялась.

## Ручная приёмка на обычном Mac

| Проверка | Ожидаемый результат |
|---|---|
| Запуск из Terminal | Окно 1280×800, в терминале OpenGL 4.1, без ошибок текстур/шейдеров |
| Начальный вид | J2000, PAUSED, внутренние орбиты, карточка Земли, видимое предупреждение об увеличенных радиусах |
| Space / кнопка Play | Дата меняется; пауза останавливает орбитальное и осевое вращение |
| `+`, `-`, B, `[`, `]` | Скорость меняется, направление обращается, шаги ровно по суткам |
| T → 2000-02-29 | Дата принимается; 1900-02-29 отклоняется с подсказкой |
| 1800-01-01 и 2050-01-01 | Граница, остановка; за пределы через проигрывание выйти нельзя |
| 0–8 и кнопки списка | Выбранное тело в центре, карточка и камера обновляются, слежение сохраняется при движении |
| Правая кнопка и scroll | Камера плавно вращается/масштабируется, не переворачивается на полюсе |
| R и V | Возврат к внутренней/полной системе |
| M | Сферы переходят в физический масштаб, подписи остаются условными указателями |
| `,`, `.`, K, P | Меняются только параметры визуализации; JD и физические значения карточки сохраняются |
| O, X, L | Независимо скрываются линии орбит, оси и подписи |
| Уран и Венера | Направленная ось >90°; обратное время обращает оба вида движения |
| Сатурн | Кольца связаны с положением и наклоном планеты |
| Retina / изменение размера | Правильные пропорции, читаемый HUD, клики совпадают с кнопками |
| Свернуть и восстановить | Нет большого скачка времени и деления на нулевую высоту |
| Текстуры | Земля с картой поверхности, на освещённой стороне виден рельеф текстуры; ночная сторона затемнена |
| Esc | Чистое завершение; во вводе даты Esc только отменяет ввод |

Записать результат каждого пункта и версию GPU. Если нужны изображения для отчёта:

```sh
./build/SolarSystem --select 3 --frames 4 --screenshot earth.ppm
./build/SolarSystem --select 7 --offscreen --screenshot uranus.ppm
```

Внеэкранный путь использует тот же рендеринг, но не проверяет GLFW-ввод. PPM — стандартное изображение без сжатия; скриншоты не созданы в текущей поставке, поскольку контекст недоступен.
